# Retro – CSS en JavaScript samenvoegen

## Wat heb ik gedaan?

Ik heb de CSS- en JavaScript-bestanden samengevoegd in `dashboard.css` en `dashboard.js`. Alle pagina’s gebruiken nu deze bestanden. Ook heb ik de mp4-achtergronden gecontroleerd.
ik heb dit ook opgezocht hoe dit moet
1. Klik op Invoegen (Insert).
2. Vul de gegevens in, bijvoorbeeld 100 kg bankdrukken.
3. Klik onderaan op Starten (Go).
Stap 3: Gegevens wijzigen
1. Klik op Bladeren (Browse).
2. Zoek de prestatie die je wilt wijzigen.
3. Klik op Wijzigen (Edit), naast de betreffende rij.
4. Pas het resultaat aan.
5. Klik op Starten (Go) om op te slaan.
Stap 4: Gegevens verwijderen
1. Klik op Bladeren (Browse).
2. Zoek de rij die je wilt verwijderen.
3. Klik op Verwijderen (Delete) en bevestig.
Tip: Gebruik INSERT om gegevens toe te voegen, UPDATE om ze te wijzigen en DELETE om ze te verwijderen. In phpMyAdmin kun je dit ook via het tabblad SQL doen.
